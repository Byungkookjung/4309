Two little widgets

Today’s work & pay. Today’s tasks.

Download Scriptable script

Set up once

  1. Install Scriptable on your iPhone.
  2. Download the script. Open it with Scriptable, or paste its contents into a new script named Pocket Paws.
  3. Run it and choose Connect / switch account.
  4. In the browser, sign in and confirm the account. Allow the return to Scriptable.
  5. Add two Scriptable widgets to your Home Screen. Choose Pocket Paws as the script for both.
  6. Set the first widget’s Parameter to work, and the second to todo. Start with Medium size.

Your data stays private

No public data feed. Login is encrypted in transit to the script and stored in Scriptable’s Keychain. The script reads your existing account; it never edits tasks or shifts.

The login credential has your account permissions, not a technically read-only scope. Only install the original script. Disconnect removes its local credentials and cached summaries; it does not remotely revoke copied credentials.

iOS decides refresh timing. No exact midnight or instant refresh guarantee. Tap a widget to edit in the website, then run its preview to request a fresh sync. Old-day cached records are never shown as today.

Preview inside Scriptable and real-device Google sign-in still need testing on your iPhone.
